# KINETIX Project Rules: Copywriting & Design Integrity

Whenever editing or generating copy for this project, you MUST strictly adhere to the following rules:

1. **Strict Character Count Parity (±3% to ±5%)**:
   - Count the exact characters of the existing text before touching it.
   - The replacement copy MUST match the original length closely and **NEVER exceed original length** if it risks an extra line wrap, card height expansion, or grid disruption.
2. **Zero Design Disruption**:
   - Do NOT alter any CSS font sizes, font families, font weights, line heights, paddings, margins, flex/grid properties, or spacing.
   - Do NOT alter HTML tags, class names, IDs, or structural wrappers.
3. **50-Year Direct-Response Standards**:
   - Zero AI buzzwords (`elevate`, `watch your brand come to life`, `innovative`, `seamless`, `unlock potential`).
   - Zero em dashes (`—`).
   - Fix all broken English/jargon (e.g. replacing `100+ Premium Quality`).
   - Fix cognitive disconnects (e.g. `How it Works` button opening a Showreel).
   - Clear client commercial outcomes (Higher retention, conversion lift, pipeline growth, ROI).
